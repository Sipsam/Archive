# 제출 안내

## 프로젝트 목적

게임 전투 로그를 기반으로 밸런스 검토 후보를 찾고, 관련 데이터와 가상 조정 시나리오를 사람의 최종 검토로 전달하는 AI Agent PoC입니다. League of Legends 형식 데이터와 가상 RPG 예제 데이터를 지원합니다.

## 핵심 기능

- CSV 데이터 로딩과 컬럼 정규화
- 패치·챔피언·대표 아이템·포지션 조합별 성능 집계
- 최소 표본 수와 95% Wilson 승률 신뢰구간 기반 검토 후보 탐지
- 패치 전후 및 사용자 세그먼트 분석
- OpenAI Tool calling 실행 흐름과 Trace 표시
- 가상 패치 후보와 가정 기반 영향 시나리오 작성
- Agent 자기반성과 재테스트 계획 작성
- Human-in-the-loop 승인·반려·재테스트 기록

## Agent 분석 흐름

1. 데이터 구조와 품질을 확인합니다.
2. 통계 기준을 만족하는 밸런스 검토 후보를 찾습니다.
3. 패치 전후 및 티어·세그먼트별 영향을 비교합니다.
4. 관련 챔피언·아이템·스탯·패치 근거를 조회합니다.
5. 조정 후보, 위험 요소와 재테스트 계획을 작성합니다.
6. 가상 패치와 휴리스틱 기반 시나리오 추정을 생성합니다.
7. Agent가 한계와 과조정 위험을 자체 검토합니다.
8. 최종 판단을 사람에게 넘기고 검토 상태를 기록합니다.

## 적용된 개선 사항

- 앱 버전 `2.8.0` 단일 관리
- 실제 비밀 파일 제거 및 `.env.example` 제공
- `qagent_core`로 설정·통계·데이터 로딩·저장 로직 일부 분리
- 이상 후보에 95% Wilson 신뢰구간 적용
- 기존 Tool 응답의 `anomaly_score` 호환성 유지
- HITL SQLite 기본 저장소와 기존 CSV/JSON 호환 기록 적용
- 실제 CSV 기준 데이터 요약 재생성 도구 제공
- 핵심 자동 테스트 및 Tool Schema 계약 테스트 추가
- 가상 패치 결과를 예측이 아닌 휴리스틱 시나리오로 명시
- 실행·보안·한계 문서 보완

## PoC로 가능한 일

- 밸런스 담당자가 검토할 후보 범위를 줄이는 일
- 데이터 근거와 Tool 호출 흐름을 시연하는 일
- 조정 아이디어와 재테스트 질문을 만드는 일
- 가상 패치 가정을 비교하고 사람의 의견을 기록하는 일

## 운영 서비스 전 필요한 일

- 사용자 인증과 역할 기반 권한
- PostgreSQL 등 중앙 HITL·감사 저장소
- Secret Manager와 키 순환 정책
- 외부 API timeout, retry, 비용 및 호출량 제한
- CI/CD, 컨테이너 배포, 모니터링과 장애 복구
- 데이터셋 버전·해시·수집 시점 기반 계보 관리
- 픽률·밴률·상대 조합 등 추가 데이터와 통계 백테스트
- 다중 비교 보정과 패치 효과 검증

## 주의사항

- Agent가 제시하는 후보는 밸런스 이상 확정 판정이 아닙니다.
- 가상 패치 수치는 실제 미래 승률을 보증하지 않습니다.
- AI가 라이브 게임 수치를 자동 승인하거나 적용해서는 안 됩니다.
- 최종 결정은 데이터 품질, 게임 디자인 의도와 QA 결과를 확인한 사람이 내려야 합니다.
- `.env`, API 키 파일, Riot 수집 원본, 계정·매치 ID, 개인 HITL 기록은 제출물에서 제외합니다.
- `report/`의 PDF·PPT·DOCX는 코드와 별도 산출물입니다. 현재 v2.8.0 구현 내용과 일치하는지 사람이 검토한 뒤 제출 여부를 결정해야 합니다.
