# 산업재해 공표자료 출처와 재생성

대상 자료는 고용노동부 공고 제2026-60호 「2025년 산업재해 발생건수 등 공표」다. 자료명 기준 연도는 2025년, 발표일은 2026-01-29다. 개별 사고 발생 연도와 발표 연도는 다르다.

## 출처

- [공식 발표](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=18907)
- [공표 명단 PDF, 28쪽](https://www.moel.go.kr/common/downloadFile.do?bbs_id=12&bbs_seq=18907&file_ext=pdf&file_seq=20260101830)
- [보도자료 PDF, 12쪽](https://www.moel.go.kr/common/downloadFile.do?bbs_id=12&bbs_seq=18907&file_ext=pdf&file_seq=20260101829)

사용자가 제공한 두 PDF를 읽어 명단의 표 38개에서 원문 행 376개를 추출했다. 중대산업사고 및 원·하청 통합공표 표의 두 번째 열 머리글 3개는 기록에서 제외했다. 동일 회사·사업장의 복수 공표 구분과 원청·하청·현장명을 보존하며 고유 사업장 수로 해석하지 않는다.

| 공표 구분 | 원문 행 수 |
|---|---:|
| 연간 사망재해자 2명 이상 | 11 |
| 동규모·동업종 평균 이상 사망만인율 | 329 |
| 중대산업사고 | 7 |
| 산재 은폐 | 2 |
| 산재 미보고 | 9 |
| 원·하청 통합공표 | 2 |
| 구 시행령 중대재해·재해율 | 16 |
| 합계 | 376 |

사망만인율 구분의 발생 연도별 행 수는 2024년 50, 2023년 152, 2022년 84, 2021년 26, 2020년 11, 2019년 6이다. 산재 미보고는 원문이 2022-2024년 기간을 제시하므로 단일 occurrenceYear를 만들어 넣지 않았다.

## 데이터 보존과 매칭

`assets/safety_disclosures/2025.json`에 원문 사업장명, 당사자별 검색 별칭, 주소, 업종, 발생 연도, 공표 구분, PDF 쪽수·표·행 번호, 원문 셀과 PDF SHA-256을 저장했다. 별칭은 원문에 명시된 회사명과 구 상호만 사용하며 지점·공장명을 제거하지 않는다. 현장명은 원문 표시에서 보존한다.

검색 결과의 이름·주소 일치는 문자열을 보수적으로 정규화한 대조 결과다. 사업자등록번호나 사업장관리번호에 의한 신원 확인을 뜻하지 않는다. 이름만 일치하거나 유사한 경우에는 원문의 현장과 주소 확인이 필요하다. 결과 없음은 이 자료 안의 검색 결과이며 무재해·안전 판정이 아니다.

## 재생성

pdfplumber가 설치된 Python 환경에서 실행한다. 애플리케이션 실행 시 PDF 추출 도구나 외부 API는 필요하지 않다.

```powershell
python scripts/build_safety_disclosures.py --list-pdf '<공표명단.pdf>' --release-pdf '<보도자료.pdf>' --frontend-copy '../WOOWANGTHON_TEAM_49_FE/src/mocks/data/safety-disclosures-2025.json'
```

추출기는 이 자료 버전의 페이지·표·유형별 행 수와 발생 연도별 행 수를 확인한다. 새 연도의 자료를 받으면 해당 구조와 기준을 검토하고 추출기·출처·검증을 함께 갱신해야 한다. 단순히 파일명만 바꾸어 사용하지 않는다. 생성한 두 JSON 사본은 바이트 단위로 같아야 한다.

원본 PDF 2쪽과 25쪽을 이미지로 렌더링해 다중 행 사업장명, 원청·하청, 표 머리글과 발생 연도 구분을 확인했다. 중간 추출·렌더링 결과는 Git 제외 `tmp/pdfs/`에 둔다.
